# NewsFlow AI — مشروع أتمتة قناة يوتيوب

منصة Python لبناء خط إنتاج أخبار عربي: جمع RSS، إزالة التكرار، إعداد مسودات تحريرية، توليد تعليق صوتي وفيديو، ثم رفع اختياري إلى YouTube عبر GitHub Actions.

> **وضع آمن افتراضي:** التشغيل ينتج ملفات محلية/Artifacts ولا ينشر تلقائياً. لا يتم الرفع إلا بعد إعداد أسرار YouTube وتفعيل `YOUTUBE_UPLOAD_ENABLED=true`. اجعل الخصوصية `private` أولاً وراجع المحتوى قبل النشر العام.

## المزايا الحالية
- جمع الأخبار من مصادر RSS المعرفة في `config/sources.yml`.
- إزالة التكرار واختيار القصص حسب حداثتها وتنوع المصادر.
- إنشاء نشرة عربية من حتى 8 أخبار حديثة، مع تنويع المصادر وإظهار روابطها وإسناد كل خبر لمصدره.
- إنشاء تعليق صوتي عربي وفيديو يومي مع عنوان موجز وكلمات مفتاحية ووسوم وهاشتاجات مرتبطة بالأخبار.
- إنشاء فيديو طويل ونسخة قصيرة (Shorts) من القصة المختارة.
- GitHub Actions للتشغيل اليدوي والمجدول وحفظ النتائج كـ Artifacts.
- رفع اختياري إلى YouTube Data API v3 بعد إعداد OAuth.

## تشغيل محلي
1. Python 3.11+ وFFmpeg.
2. `pip install -r requirements.txt`
3. انسخ `.env.example` إلى `.env` واضبط الإعدادات عند الحاجة.
4. `python -m newsflow --dry-run`
5. النتائج في `output/`.

## GitHub Actions
من تبويب Actions شغّل `NewsFlow pipeline` يدوياً. التشغيل المجدول يعمل يومياً الساعة 06:00 UTC. أضف الأسرار المطلوبة في Settings → Secrets and variables → Actions عند رغبتك في تفعيل الرفع:
- `YOUTUBE_CLIENT_ID`
- `YOUTUBE_CLIENT_SECRET`
- `YOUTUBE_REFRESH_TOKEN`

ثم أضف متغيراً `YOUTUBE_UPLOAD_ENABLED=true`. التشغيل اليدوي العادي مع `dry_run=false` و`private_test=false` يرفع الفيديو الطويل والقصير باستخدام `YOUTUBE_PRIVACY_STATUS` (الافتراضي `private`). خيار `private_test=true` يرفع فيديو طويلاً واحداً بخصوصية `private`. التشغيل المجدول يومياً الساعة 06:00 UTC (08:00 صباحاً بتوقيت القاهرة في التوقيت الشتوي) ينتج الفيديو ويحفظه كـ Artifact للمراجعة، ولا يرفعه تلقائياً. الرفع متاح في التشغيل اليدوي فقط بعد تفعيل المتغير وإعداد أسرار OAuth. الرفع معطل افتراضياً.

## هوية WealthRadar وبيانات الفيديو
- اسم القناة المستخدم في النص والصورة الوصفية: WealthRadar.
- عنوان النشرة يتضمن عبارة البحث الأساسية «أخبار اقتصادية اليوم» وعدد الأخبار الفعلي، مع اسم القناة.
- الوصف يضم روابط المصادر وإخلاء مسؤولية و3 هاشتاجات كحد أقصى؛ والوسوم (Tags) تضاف في بيانات الفيديو.
- لا يضمن RSS صحة الخبر بشكل مستقل؛ يجب مراجعة الأرقام والسياق قبل النشر.

## تنبيه تحريري وحقوقي
هذا المشروع لا يثبت صحة الخبر آلياً ولا يمنح حق إعادة استخدام صور أو مقاطع المصادر. يستخدم بيانات RSS والعناوين والروابط، ويكتب ملخصاً أصلياً أولياً. يجب مراجعة الوقائع والأرقام والأسماء وحقوق الوسائط قبل النشر. لا تنشر إشاعة أو خبراً عاجلاً غير مؤكد.

## هيكل المشروع
- `newsflow/`: وحدات الجمع والتحرير والصوت والفيديو والنشر.
- `config/sources.yml`: مصادر RSS.
- `.github/workflows/newsflow.yml`: الأتمتة.
- `.env.example`: أسماء الإعدادات دون أسرار.
