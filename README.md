# NewsFlow AI — مشروع أتمتة قناة يوتيوب

منصة Python لبناء خط إنتاج أخبار عربي: جمع RSS، إزالة التكرار، إعداد مسودات تحريرية، توليد تعليق صوتي وفيديو، ثم رفع اختياري إلى YouTube عبر GitHub Actions.

> **وضع آمن افتراضي:** التشغيلات المجدولة تجمع الأخبار وتتحقق من حداثتها وتنتج مسودات وتقارير فقط. لا يبدأ الرندر أو رفع YouTube تلقائياً. أي اختبار رفع يدوي يتطلب موافقة تحريرية وفحصاً بصرياً صريحين، والخصوصية PRIVATE فقط.

## المزايا الحالية
- جمع الأخبار من مصادر RSS المعرفة في `config/sources.yml` مع إزالة التكرار ومراعاة حداثة النشر.
- فلتر موضوعي يستبعد الأخبار الرياضية والعامة التي لا تحمل صلة مالية أو اقتصادية واضحة، مع تنويع المصادر (حتى 3 أخبار من المصدر الواحد).
- تقرير مراجعة `editorial_review.json` يوضح المقبول والمرفوض والتحذيرات، ويشير صراحةً إلى أن التحقق المستقل من الوقائع لم يُنفذ آلياً.
- إعداد مسودات تحريرية عربية مع روابط المصادر وإسناد كل خبر لمصدره.
- اختبارات تلقائية لمسارات CLI والرندر والتحقق من وجود الصوت والصورة وتقارب مدة الفيديو مع الصوت.
- استخدام YouTube Data API v3 الرسمية فقط للرفع.
- مراجعة بشرية إلزامية قبل أي رفع؛ اجتياز الفلتر الآلي لا يعني التحقق من صحة الخبر أو الأرقام.

## تشغيل محلي
1. Python 3.11+ وFFmpeg.
2. `pip install -r requirements.txt`
3. انسخ `.env.example` إلى `.env` واضبط الإعدادات عند الحاجة.
4. `python -m newsflow --dry-run`
5. النتائج في `output/`.

## GitHub Actions والجدول اليومي
تعمل جدولة NewsFlow وفق توقيت `Africa/Cairo` في ثلاثة مواعيد يومياً:
- 3:00 عصراً بتوقيت القاهرة.
- 7:00 مساءً بتوقيت القاهرة.
- 10:00 مساءً بتوقيت القاهرة.

يحوّل GitHub Actions المواعيد إلى UTC تلقائياً عبر مجموعتي cron:
- التوقيت الشتوي في القاهرة (UTC+2): 13:00 و17:00 و20:00 UTC.
- التوقيت الصيفي في القاهرة (UTC+3): 12:00 و16:00 و19:00 UTC.

يتحقق `newsflow.schedule` من الحدث الفعلي، والتوقيت الموسمي، ونافذة التأخير. تشغيلات cron الخاصة بالموسم غير النشط تُتخطى بوضوح، كما تُتخطى أحداث push وpull request في بوابة الجدولة ولا تبدأ خط إنتاج الأخبار. تشغيلات الجدول اليومية **للجمع والتحقق وإعداد المسودات والتقرير فقط**؛ لا تولّد صوتاً، ولا ترندر فيديو، ولا تتصل بـYouTube.

من تبويب Actions يمكن تشغيل `NewsFlow pipeline` يدوياً. يظل `dry_run=true` هو الوضع الافتراضي. لاختبار PRIVATE يدوي، يجب إيقاف dry-run وتحديد private_test والموافقة التحريرية والموافقة على فحص المعاينة الفعلية. هذه الموافقات لا تُفعل تلقائياً في التشغيل المجدول.

**الرفع الخاص للمراجعة:** ظهور صاحب القناة أمام الكاميرا ليس شرطاً لفيديو أخبار يعتمد على التعليق الصوتي ولقطات B-roll. يمكن استخدام نسخة صوتية معتمدة من صوته، مع توثيق لقطات الفيديو المرخصة. الرفع المجدول يظل `PRIVATE` فقط، ويُوسم الوصف بأنه نسخة مراجعة لا يجوز نشرها قبل التحقق المستقل من الوقائع ومراجعة المالك. لا يوجد نشر عام آلي.

**متطلبات OAuth:** فحص ملكية قناة WealthRadar يستخدم `channels.list(mine=true)`، لذلك يلزم أن يتضمن التفويض النطاقين `youtube.upload` و`youtube.readonly`. تحديث الكود لا يضيف النطاق الجديد تلقائياً إلى Refresh Token قديم؛ أعد تفويض نفس OAuth Client بالنطاقين بعد مراجعة التغييرات والموافقة عليها، وحدّث `YOUTUBE_REFRESH_TOKEN` فقط. لا تضع قيم الأسرار في المستودع أو السجلات.

لا يُسمح بأي نشر PUBLIC تلقائي. أي رفع تجريبي يكون عبر YouTube Data API الرسمية وبخصوصية `private`، ولا يُعتبر ناجحاً إلا بعد التحقق من القناة المستهدفة وVideo ID والرابط وحالة الخصوصية.

## هوية WealthRadar وبيانات الفيديو
- اسم القناة المستخدم في النص والصورة الوصفية: WealthRadar.
- عنوان النشرة يتضمن عبارة البحث الأساسية «أخبار اقتصادية اليوم» وعدد الأخبار الفعلي، مع اسم القناة.
- الوصف يضم روابط المصادر وإخلاء مسؤولية و3 هاشتاجات كحد أقصى؛ والوسوم (Tags) تضاف في بيانات الفيديو.
- لا يضمن RSS صحة الخبر بشكل مستقل؛ يجب مراجعة الأرقام والسياق قبل النشر.

## تنبيه تحريري وحقوقي
هذا المشروع لا يثبت صحة الخبر آلياً ولا يمنح حق إعادة استخدام صور أو مقاطع المصادر. يستخدم بيانات RSS والعناوين والروابط، ويكتب ملخصاً أصلياً أولياً. يجب مراجعة الوقائع والأرقام والأسماء وحقوق الوسائط قبل النشر. لا تنشر إشاعة أو خبراً عاجلاً غير مؤكد.

## هيكل المشروع
- `newsflow/`: وحدات الجمع والتحرير والصوت والفيديو والنشر.
- `config/sources.yml`: مصادر RSS.
- `.github/workflows/newsflow.yml`: الأتمتة.
- `.env.example`: أسماء الإعدادات دون أسرار.
